# 档位、时段和价格

## 范围与档位

一个配送范围用平台原名、实际距离和页面显示序号描述。显示序号仅用于定位页面上的原范围。范围名为“4”且实际距离为 2.98 公里时，其距离仍为 2.98 公里。

普通档位沿用旧项目规则。对同一配送方案下的每个时段独立分类，排除明确标记为快送的范围，剩余范围按实际距离从近到远排序。同距的普通范围应附带原名定位。若原名也重复，可用经双设置页核对一致的显示序号区分。实际操作前以最新页面读数为准。

快送保留在完整范围清单中，可用原名、距离和显示序号指定。实际页面可能同时有多个不同距离的“专送”和“快送”。专送参加普通档排序，快送可以独立调整。

“全部范围”包含当前明确时段内的全部可编辑范围。逐档配置可以使用普通档位编号或范围身份。目标金额完全取本次用户指令。

## 时段

- 正常时段是平台常规生效配置。
- 夜间等固定时段按平台配置的起止时间生效，跨午夜时间按平台显示原样记录。
- 恶劣天气等手动特殊时段拥有独立范围、价格及启停状态。读取时区分已创建、开关关闭、正在生效和平台尚未提供该时段。
- 以页面显示的配送方案、时段原名和时间区分配置。短暂天气的实际关闭时间是状态，保持时段名称身份稳定。

## 金额

起送价和基础配送费均以人民币元录入，内部以分比较。顾客实际配送费还会受加价和减配活动影响。基础配送费编辑只写基础金额，加价规则保留为回读对照数据。
